# Датасет

Документ описывает данные, на которых обучена модель кукурузы TomatoCare: состав, структуру, подготовку и известные ограничения.

## Общие сведения

| Параметр | Значение |
|---|---|
| Культура | кукуруза |
| Задача | классификация фотографии листа |
| Число классов | 4 (3 заболевания + здоровый лист) |
| Всего изображений | 5 097 |
| Источник | Kaggle (несколько датасетов, в том числе PlantVillage: https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset) |

## Классы

Индексы классов определяются алфавитным порядком названий папок (так их нумерует `torchvision.datasets.ImageFolder`). Этот же порядок записан в `classes.json`.

| Индекс | Класс | Состояние |
|---|---|---|
| 0 | `Common_rust` | Обыкновенная ржавчина |
| 1 | `Gray_leaf_spot` | Серая пятнистость (церкоспороз) |
| 2 | `Northern_Leaf_Blight` | Северная пятнистость (гельминтоспориоз) |
| 3 | `healthy` | Здоровый лист |

## Структура и разбиение

Данные разделены на три непересекающиеся выборки и хранятся в формате «одна папка — один класс»:

```
train/
  Common_rust/
  Gray_leaf_spot/
  ...
valid/
  ...
test/
  ...
```

| Выборка | Изображений | Доля | Назначение |
|---|---|---|---|
| `train` | 3 566 | ≈ 70 % | обучение |
| `valid` | 763 | ≈ 15 % | выбор лучшей эпохи по val_loss |
| `test` | 768 | ≈ 15 % | итоговая оценка, используется один раз после обучения |

Количество изображений по классам:

| Класс | train | valid | test | Всего |
|---|---|---|---|---|
| `Common_rust` | 913 | 195 | 197 | 1 305 |
| `Gray_leaf_spot` | 399 | 85 | 87 | 571 |
| `Northern_Leaf_Blight` | 798 | 171 | 172 | 1 141 |
| `healthy` | 1 456 | 312 | 312 | 2 080 |

Классы не идеально сбалансированы: самый крупный (`healthy`) примерно в 3,6 раза больше самого малочисленного (`Gray_leaf_spot`). Это отражается на метриках: у `Gray_leaf_spot` самые низкие precision и F1, а в тесте всего 87 изображений, поэтому оценка по этому классу менее устойчива.

## Подготовка

1. **Приведение классов.** Названия классов из разных источников приведены к единым (`Common_rust`, `Gray_leaf_spot`, `Northern_Leaf_Blight`, `healthy`). Папка «Insects damage» (повреждения насекомыми) из одного из датасетов в выборку не включена, так как не входит в набор классов.
2. **Исключение аугментированных копий.** Из одного из датасетов заранее убраны 8 757 файлов с суффиксами `_aug` и `_enhanced`: это готовые повёрнутые, отражённые и улучшенные копии исходных снимков. Проверка по хэшу их не находит, и они могли бы попасть в разные выборки (утечка данных). Аугментация выполняется только при обучении.
3. **Удаление дубликатов.** Скрипт `ml/corn/prepare_dataset.py` ищет дубликаты сразу во всех источниках и до разбиения на выборки: точные (MD5 файла) и почти точные (dHash изображения, порог 2). Из 9 899 найденных файлов удалено 4 796 дубликатов (из них 4 791 точных по MD5); ещё 6 файлов удалено из-за конфликта меток (одно и то же изображение подписано разными классами). В итоговую выборку вошли изображения только двух из трёх скачанных датасетов, остальные оказались копиями.
4. **Разбиение на выборки.** Стратифицированное разбиение 70/15/15 (seed = 42) выполнено после удаления дубликатов; файлы `valid` и `test` в обучении не участвуют.

## Обучающие преобразования

Только для `train` применяется аугментация: случайное горизонтальное отражение (p = 0,5), поворот до ±15°, изменение яркости, контраста и насыщенности (±20 %). Для `valid` и `test` выполняются только приведение к размеру 224 × 224 и нормализация.

## Известные ограничения

- Почти одинаковые изображения ищутся только по хэшу (dHash): повёрнутые или отражённые копии и разные снимки одного и того же растения скрипт не находит. Если такие пары остались, итоговая точность на `test` немного завышена. Для независимой оценки модель проверена на фотографиях из интернета (см. `model.md`).
- В исходных датасетах встречаются изображения, подписанные разными классами (удалено 6 таких файлов); не исключены и другие ошибки разметки, особенно между `Gray_leaf_spot` и `Northern_Leaf_Blight`.
- Изображения датасета в основном сняты крупным планом листа. На дальних планах и в сложных сценах качество модели заметно ниже (см. `model.md`).
- `Gray_leaf_spot` — самый малочисленный класс (571 изображение).
- Сами изображения в репозиторий не включаются.

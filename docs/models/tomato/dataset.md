
# Датасет

Документ описывает данные, на которых обучена модель распознавания болезней томата TomatoCare: источники изображений, состав классов, подготовку, разбиение и известные ограничения.

| Параметр | Значение |
|---|---|
| Культура | томат |
| Задача | классификация изображения листа |
| Число классов | 7 (6 заболеваний + здоровый лист) |
| Всего изображений | 23 394 |
| Обучающая выборка | 16 373 |
| Валидационная выборка | 3 505 |
| Тестовая выборка | 3 516 |
| Основной источник | [Kaggle – Tomato](https://www.kaggle.com/datasets/ashishmotwani/tomato) |
| Дополнительный источник | [Kaggle – Tomato Leaf Disease](https://www.kaggle.com/datasets/yusufmurtaza01/tomato-leaf-disease) |

Основной источник изображений листьев томата, распределённых по категориям заболеваний и здоровых растений.

### 2. Дополнительный датасет

Изображения из двух источников объединены в общий датасет.

## Классы

Индексы классов определяются алфавитным порядком названий каталогов, как это делает `torchvision.datasets.ImageFolder`. Этот порядок используется при обучении модели и сохраняется в `classes.json`.

| Индекс | Класс | Описание |
|---:|---|---|
| 0 | `Bacterial_spot` | Бактериальная пятнистость |
| 1 | `Early_blight` | Альтернариоз |
| 2 | `Late_blight` | Фитофтороз |
| 3 | `Leaf_Mold` | Листовая плесень (кладоспориоз) |
| 4 | `Septoria_leaf_spot` | Септориоз |
| 5 | `Tomato_mosaic_virus` | Вирус мозаики томата |
| 6 | `healthy` | Здоровый лист |

## Структура и разбиение

Датасет организован в формате «одна папка – один класс»:

```text
dataset/
├── train/
│   ├── Bacterial_spot/
│   ├── Early_blight/
│   ├── Late_blight/
│   ├── Leaf_Mold/
│   ├── Septoria_leaf_spot/
│   ├── Tomato_mosaic_virus/
│   └── healthy/
├── valid/
│   └── ...
└── test/
    └── ...
```

Разбиение выполнено в пропорции приблизительно 70/15/15. Изображения распределялись случайным образом отдельно для каждого класса.

| Выборка | Изображений | Доля | Назначение |
|---|---:|---:|---|
| `train` | 16 373 | 70,0 % | Обучение модели |
| `valid` | 3 505 | 15,0 % | Выбор лучшей эпохи |
| `test` | 3 516 | 15,0 % | Итоговая оценка модели |

## Подготовка данных

1. **Объединение источников.** Изображения основного датасета дополнены изображениями из второго набора данных.
2. **Удаление дубликатов.** Выполнялся поиск и удаление дубликатов изображений, в том числе между классами. При проверке по SHA-256 выявляются файлы с идентичным содержимым; визуально похожие изображения с разным содержимым файла могут сохраниться.
3. **Исключение классов.** Из итогового набора исключены четыре категории: `Tomato_Yellow_Leaf_Curl_Virus`, `Target_Spot`, `powdery_mildew` и `Spider_mites Two-spotted_spider_mite`.
4. **Разбиение на выборки.** Изображения распределены между `train`, `valid` и `test` в пропорции 70/15/15.
5. **Аугментация.** Случайные преобразования применяются во время обучения и не изменяют сохранённые изображения датасета.

## Баланс классов

Датасет не идеально сбалансирован, однако количество изображений по классам относительно близкое.

Наиболее многочисленный класс – `Late_blight` (3 733 изображения), наименее многочисленный – `Early_blight` (2 753 изображения). Соотношение размеров этих классов составляет приблизительно 1,36:1.

При обучении используется стандартная функция потерь `CrossEntropyLoss` без дополнительных весов классов.

## Ограничения

- Датасет сформирован из публичных наборов изображений Kaggle, поэтому его распределение может отличаться от изображений растений в реальных условиях Беларуси.
- Удаление точных дубликатов не гарантирует отсутствия визуально одинаковых изображений, сохранённых в разных разрешениях или с разным сжатием.
- Высокие метрики на тестовой выборке сами по себе не подтверждают такую же точность на фотографиях, сделанных пользователями приложения.
- Необходимо отдельно проверять качество распознавания на независимых фотографиях реальных растений.

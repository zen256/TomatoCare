# Модель

Документ описывает нейросеть, используемую в TomatoCare: архитектуру, обучение, экспорт в ONNX и интеграцию в приложение.

## Кратко

| Параметр | Значение |
|---|---|
| Архитектура | EfficientNet-B0 (предобучена на ImageNet, дообучена целиком) |
| Задача | классификация на 10 классов |
| Вход | RGB-изображение 224 × 224 |
| Выход | 10 значений (логиты), по одному на класс |
| Фреймворк обучения | PyTorch + torchvision |
| Формат в приложении | ONNX, один файл `efficientnet_b0.onnx` |
| Точность на тесте | 98,64 % (3389 изображений) |

## Обучение

Скрипт: `ml/train.py`. Он ожидает папки `train/`, `valid/`, `test/` в каталоге запуска, поэтому запускать его нужно из папки с датасетом.

Последний слой `classifier[1]` заменён на `Linear(1280, 10)`; остальные веса стартуют с ImageNet и тоже обучаются (заморозки слоёв нет).

| Параметр | Значение |
|---|---|
| Размер изображения | 224 × 224 (прямое масштабирование без обрезки) |
| Размер батча | 64 |
| Число эпох | 10 |
| Оптимизатор | AdamW |
| Learning rate | 0,0001 |
| Weight decay | 0,0001 |
| Функция потерь | CrossEntropyLoss |
| Аугментация | отражение по горизонтали, поворот ±15°, ColorJitter (яркость, контраст, насыщенность по 0,2) |
| Нормализация | mean = [0.485, 0.456, 0.406], std = [0.229, 0.224, 0.225] |
| Устройство | CUDA (GPU) |

Лучшая эпоха выбирается по accuracy на `valid`: это 7-я эпоха (0,9905). Её веса сохраняются и затем один раз проверяются на `test`.

В скрипте не зафиксирован random seed, поэтому повторный запуск даст близкие, но не идентичные результаты.

Зависимости обучения: `torch`, `torchvision`, `scikit-learn`, `matplotlib`.

## Экспорт в ONNX

Скрипт: `ml/export_onnx.py`.

Модель необходимо сохранять **одним файлом**. При экспорте с внешними весами рядом появляется файл `.onnx.data`; если его не положить в `assets` вместе с `.onnx`, ONNX Runtime в приложении не сможет загрузить модель, и анализ завершится ошибкой. Поэтому в приложение добавляется только самодостаточный `efficientnet_b0.onnx`.

## Интеграция в приложение

За распознавание отвечает класс `TomatoClassifier` (ONNX Runtime). Предобработка в приложении должна в точности повторять предобработку при обучении:

1. Изображение приводится к RGB.
2. Масштабируется до 224 × 224 напрямую, без обрезки по центру и без сохранения пропорций.
3. Значения пикселей переводятся в диапазон 0–1 и нормализуются (mean и std из таблицы выше).
4. Формируется тензор `float32` формы `[1, 3, 224, 224]` (порядок каналов CHW).
5. Модель возвращает 10 логитов; к ним применяется softmax. Индекс максимума сопоставляется с `classes.json`, значение максимума — уверенность модели.

Расхождения в любом из пунктов (порядок каналов, нормализация, другой способ масштабирования) дают заметное падение точности без каких-либо ошибок в работе приложения. Порядок классов в `classes.json` из `assets` должен совпадать с порядком из `ml/classes.json`.
